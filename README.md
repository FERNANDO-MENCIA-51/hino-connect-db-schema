# 🚗 HINO Connect - Sistema de Gestión de Vehículos

Sistema web para la administración y gestión de vehículos, conductores y movimientos de la empresa HINO.

## 🎨 Características

- ✅ Autenticación JWT
- ✅ Dashboard con estadísticas
- ✅ Gestión de Vehículos (CRUD completo)
- ✅ Gestión de Conductores (CRUD completo)
- ✅ Gestión de Movimientos
- ✅ Sidebar colapsable
- ✅ Notificaciones y mensajes
- ✅ Alertas estilo iOS con SweetAlert2
- ✅ Diseño responsive
- ✅ Animaciones suaves

## 🚀 Inicio Rápido

### Prerrequisitos

- Node.js 18+
- npm o yarn
- Backend corriendo en `http://localhost:8081`

### Instalación

```bash
# Clonar el repositorio
cd HP-Front-end

# Instalar dependencias
npm install

# Iniciar en modo desarrollo
npm run dev
```

El proyecto estará disponible en `http://localhost:5173`
